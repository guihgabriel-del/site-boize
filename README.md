# Site Boize pronto para Vercel

Projeto em React + Vite, pronto para subir no Vercel.

## Como publicar

### Opção 1 — pelo GitHub + Vercel
1. Crie um repositório no GitHub.
2. Envie todos os arquivos desta pasta para o repositório.
3. Acesse https://vercel.com
4. Clique em **Add New > Project**.
5. Importe o repositório.
6. O Vercel vai reconhecer automaticamente como projeto Vite.
7. Clique em **Deploy**.

### Opção 2 — pelo terminal
```bash
npm install
npm run build
```
Depois conecte ao Vercel ou use o CLI da plataforma.

## Personalizações rápidas
- E-mail de contato: editar em `src/App.jsx`
- Textos institucionais: editar em `src/App.jsx`
- Cores e visual: editar em `src/styles.css`

## Observação
Este projeto foi estruturado com base na apresentação institucional da Boize, incluindo serviços, posicionamento, pesquisas e parceria estratégica com ICN Agency.
